# Esta-o-Meteorol-gica-IoT-Dashboard-com-K-Means
Projeto de ponta a ponta focado em Internet das Coisas e Ciência de Dados. Coleta de dados ambientais via ESP32, armazenamento em nuvem no Firebase e um backend em Python (Flask) que aplica o algoritmo K-Means para segmentar perfis climáticos em um painel web ao vivo.
